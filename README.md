# 115資優班新生分組工具

這是一個給特推會現場使用的新生抽籤分組小工具。打開 HTML 檔後，可以依年級分別抽出創造力資優班新生的分組結果。

## 功能

- 三年級新生分組
- 五年級新生分組
- 每組最多 3 人
- 若最後剩 4 人，會自動拆成 2 人、2 人
- 可複製分組結果
- 可列印分組結果

## 使用方式

1. 開啟 `115資優班新生分組工具.html`
2. 依現場需求點選：
   - `三年級新生分組`
   - `五年級新生分組`
3. 系統會立即產生隨機分組結果
4. 可按 `複製結果` 貼到文件或訊息中
5. 可按 `列印` 直接列印結果

## 分組名單

本工具只包含創造力資優班新生，不包含一般智能資優新生。

- 三年級新生：14 人
- 五年級新生：8 人
